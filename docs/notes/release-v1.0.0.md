# Đảo Đèn Lồng v1.0.0

Đỗ Minh Hoàng · 2A202603554 · K5-L3A. Contract v1.3, đủ nội dung bốn phase.

Tải `dao-den-long-v1.0.0-web.zip`, giải nén, mở terminal tại thư mục vừa giải nén
và chạy `node scripts/serve.mjs` (Node.js 22+). Mở http://localhost:4173 bằng trình duyệt WebGL2.
Gói có sẵn `dist/`, mã nguồn, tài liệu, giấy phép và bằng chứng. Không cần npm install để chơi gói này.

`demo.mp4` là replay tự động được render từ game đang chạy thật, kèm bằng chứng test/headless/bench/soak.
Không mô tả replay là thao tác tay. File dưới 5 phút.

Benchmark tự đo và soak đính kèm là bằng chứng trên máy phát triển;
máy chấm của giảng viên quyết định hiệu năng cuối cùng. README có lệnh tái lập,
các giả định thiết kế, hồ sơ bốn phase và hướng dẫn leaderboard/export.

Workflow chỉ phát hành sau khi test/build ba hệ điều hành và kiểm tra gói/bằng chứng đạt.
